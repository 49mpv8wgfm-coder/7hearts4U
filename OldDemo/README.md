# OldDemo — archived first attempt

The original "seven-of-hearts" build (magic.css era), preserved here as an art
library and reference. The runnable original still lives in its own repo
(seven-of-hearts); this copy's assets landed flat when uploaded via the web UI.

Contents:
- `assets/` — 52 SVG card faces, 3 card backs, 9 rose ornaments, art prompts,
  and the old manifest

The new app at the repo root deals these SVGs directly — `assets/manifest.json`
points the A♥–7♥ faces, the crimson-velvet back, and the red rose at these
files. Replace them with custom art by editing the manifest paths or dropping
new files into `assets/cards/` at the root.
